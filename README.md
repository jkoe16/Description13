# 마음곁

마음이 힘든 사람들이 편하게 이야기를 나누고 위로받을 수 있는 웹 앱의 1차 UI 초안입니다.

> UI 초안 단계입니다. AI 연결, 로그인, 데이터 저장 기능은 아직 없으며 대화 답변은 정해진 예시 문구입니다.

## 화면

| 화면 | 내용 |
|---|---|
| 홈 | 시간대별 인사, 감정 선택, 위로 문구, 대화 시작 |
| 마음 대화 | 채팅 UI, 경청 · 공감 · 함께 생각하기 · 용기 주기 선택 |
| 마음 기록 | 감정 · 강도 · 메모 기록 (새로고침하면 사라짐) |
| 마음 휴식 | 상자 호흡 · 4-7-8 호흡 · 편안한 호흡 안내 |
| 도움받기 | 109 · 112 · 119 및 상담기관 연락처 |

PC에서는 왼쪽 사이드바, 모바일(860px 이하)에서는 하단 메뉴로 이동합니다.

## 실행

```bash
npm install
npm run dev     # 개발 서버
npm run build   # dist/ 에 빌드
```

React 19 + Vite 7, 추가 라이브러리 없이 구성했습니다.
